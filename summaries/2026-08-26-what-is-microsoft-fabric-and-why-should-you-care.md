# What Is Microsoft Fabric? (And Why Should You Care?)
> 🟢 HIGH | Score: 9/10 | [Pragmatic Works](https://youtube.com/watch?v=BgOb9W14vHI) | 2026-08-26

## Shrnutí
Microsoft Fabric je integrovaná analytická platforma od Microsoftu, která kombinuje Data Engineering, Data Warehousing a Business Intelligence do jednoho ekosystému. Video vysvětluje, proč by měl datový inženýr jako Ivo tento stack zvážit, особě v kontextu Azure (který již používá). Fabric je přirozenou evolucí pro někoho pracujícího s Data Factory, Synapse a Power BI.

## Klíčové body
- Fabric unifikuje Azure Data Factory, Synapse Analytics, Power BI a lakehouse architekturu v jedné platformě
- Medallion architecture + Lakehouse design se nativně podporují v Fabric
- Jednoduší správa dat a redukce komplexity vs. řešení více Azure služeb zvlášť
- Real-time analytics a AI integrace jsou built-in (relevantní pro tvoje LLM ambice)
- Pragmatic Works jsou renomovaný zdroj pro Microsoft BI/data stack (věrohodný kanál)
